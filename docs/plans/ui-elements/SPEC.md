## Authority and connected contracts
- Existing PreviewDescriptor.views is the element catalog. Optional view.element: {owner:string,sources:string[],designGuide:string}; all paths validated, bounded, project-relative. This references canonical owner IDs, not another ownership registry. Tests check declared source files against canonical registry.
- UIPlugin.elements?: readonly {id:string,Component:ComponentType<UIPluginProps>}[] registers actual renderers, with existing supported slots unchanged. Descriptor view IDs/element route IDs reference these registrations.
- UIPluginProps.planningOptions?: {presentation?:'workspace'|'isolated',initialView?:'structure'|'board'|'journal'}; workspace defaults preserved. Kanban registers its actual PlanningView with isolated/board options; no copied board implementation.
- First-party iframe route: /?view=element&element=kanban&projectId=default. Unknown elements show an honest unavailable view. Existing ProjectWorkspace/preview ownership handles selected project and source navigation.
- Source tools live in preview Inspect drawer: source/style/guide buttons use existing fenced onSourceSelect. Copy agent brief reads live project files and hashes; guards late project/view/server changes and never sends to a provider or executes commands.
- Existing project-server owns explicit Vite frontend start/stop. Root devlab.preview.json declares4312 frontend and4311 attached backend via explicit argv. Profile permits only that declared frontend origin (fixture override for private ports). No arbitrary Origin rewriting or env allowlist weakening. Existing preview-inspector provides bridge bytes through a read-only HTTP route. Vite + pinned React plugin4.7.0 provide CSS/React refresh; compatible UI edits retain owners, owner/bootstrap changes require deliberate reload.
