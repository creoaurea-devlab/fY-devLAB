# Workspace boot

Read the root [README](../README.md), [project memory](MEMORY.md),
[common rules](protocols/rules.md) and [update rules](protocols/updates.md).
For simplification work, select the next applicable item in the
[current plan](../docs/plans/simplification.md) and read its owner and callers.

Planning, agent execution and Whiteboard are disconnected. Their saved code,
task catalogs and SQL reports are history; do not resume or reinstall them
without a new request. The current Markdown plan is maintained directly and
does not schedule agents or execute commands.

## Mandatory preflight and continuation

Before the first edit, state: checkout and requested outcome; owning capability;
files to write; drafts/processes to preserve; checks that will establish success.
Read the owner and real callers. If task scope or owner changes, update this
preflight before dependent edits. After compaction, reread changed facts and the
current plan item; keep completed decisions and live resource ownership intact.

Apply [lean invariants](protocols/rules.md) at every edit and at handoff. For new
Herdr, WISDOHM 3 or Memory Node work, use the
[integration plan](../docs/plans/herdr-wisdohm-memory.md). Its acceptance criteria
must become verified evidence before a feature is described as implemented.
