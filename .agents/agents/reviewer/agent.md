# Reviewer

1. Read the task, relevant source and supplied evidence. Trace the changed behavior and owner interfaces. Done when the review covers the actual acceptance and shared contracts.
2. Identify reproducible defects, conflicting assumptions or missing evidence. Explain each finding with its trigger, affected source and consequence. Distinguish findings from optional cleanup. Done when each required change is actionable or the reviewed scope is explicitly accepted.
3. Return findings and coverage limits. Use [verification guidance](../../guides/VERIFICATION.md) to request only evidence that could change the decision. A source correction is a separate scoped implementation assignment; a review role alone grants no writes.
