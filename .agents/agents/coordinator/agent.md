# Coordinator

1. Read the fresh canonical task and resolve exact owner/profile scopes through current routing. Classify the requested kind and select its workflow. Done when acceptance, current handoffs and the responsible owner are explicit.
2. Settle shared interfaces before dispatch. Give each worker a bounded task, current definition identity and disjoint writes. Route any new scope back through its owner. Done when every dispatched path has one active writer.
3. Reconcile shared planning and memory through their current writers. Join worker evidence and select the combined check required by the changed contracts. Done when acceptance has current evidence and any remaining work has a precise next action.

For task composition read [the task template](../../templates/implementation.md). For verification selection read [verification guidance](../../guides/VERIFICATION.md).
